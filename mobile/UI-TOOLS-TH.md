## เทมเพลต Elegant Home — 30 กันยายน 2026

ปรับรูปแบบตาม [Elegant Smart Home App ของ Digcy](https://dribbble.com/shots/27291362-App-Store-Screenshots-Elegant-Smart-Home-App)
โดยคงรหัสสีเดิมทั้งหมด ใช้ภาพห้องขนาดใหญ่ ป้ายโปร่งแสง การ์ดมุมโค้ง
ปุ่มแคปซูล ตัวเลขขนาดใหญ่ และแถบเมนูพื้นสว่างด้านล่าง ไอคอนเส้นบางพร้อมชื่อและขีดสีส้มเหนือเมนูที่เลือก ตัวอักษรหลักเป็นฟอนต์ระบบ
ผสมหัวข้อเน้นแบบ serif ตัวเอียง

- Home: ภาพรวมจำนวนอุปกรณ์ ตัวกรองห้อง ภาพห้อง Scene และปุ่มเปิด–ปิด
- Rooms: ภาพปกแต่ละห้องและการ์ดควบคุมอุปกรณ์ ใช้ตัวกรองร่วมกับ Home
- Smart Light: ภาพห้อง แถบความสว่างขนาดใหญ่ ตัวเลขเด่น และปุ่มโทนแสง
- Login, Automation, History, Settings และ AI: ใช้การ์ด ปุ่ม และระยะห่างชุดเดียวกัน
- ภาพห้องเป็นภาพตกแต่งที่สร้างด้วย AI ไม่ใช่ภาพจากกล้องหรือภาพบ้านจริงของผู้ใช้
- ภาพถูกเก็บในแอปเป็น JPEG รวมประมาณ 272 KB ดูที่ `assets/interiors.md`
- ไอคอนในหน้าจอใช้ Material Symbols ผ่าน `SynapseIcons.tsx` และ `MaterialSymbol.tsx` ส่วนแถบเมนูล่างใช้ไอคอนเส้นบางจาก Lucide

โค้ดภาพห้องอยู่ที่ `src/RoomVisual.tsx` และการจัดหน้าหลักอยู่ที่ `src/SynapseUI.tsx`

## เครื่องมือที่ใช้

| รายการ | เครื่องมือ / เทคโนโลยี | หน้าที่ |
|---|---|---|
| พัฒนา UI | React Native | สร้างหน้าจอ ปุ่ม การ์ด และเมนู |
| พัฒนาและสร้างแอป | Expo | รันและสร้างแอปสำหรับ Android, iOS และเว็บ |
| ภาษา | TypeScript / TSX | เขียนโค้ดและคอมโพเนนต์ UI |
| จัดสไตล์ | React Native `StyleSheet.create()` | กำหนดสี ขนาด ระยะห่าง มุมโค้ง และเงา |
| ชุดไอคอน | Lucide (`lucide-react-native`) | ไอคอนเส้น เช่น บ้าน หลอดไฟ พัดลม ไมค์ และตั้งค่า |
| แสดงไอคอน SVG | `react-native-svg` | วาดไอคอนในแอป |
| สร้างมาสคอต | Imagegen | สร้างภาพหุ่นยนต์โทนครีมแบบ 3D เป็น PNG พื้นหลังโปร่งใส |

## ฟอนต์และแนวสไตล์

- ฟอนต์หัวข้อ: Georgia บน iOS และเว็บ; serif บน Android โดยรูปแบบจริงขึ้นอยู่กับฟอนต์ของระบบ
- แนวภาพรวม: มินิมอลโทนอุ่น ใช้น้ำตาลและครีม พร้อมสีส้มและเหลืองเป็นสีเน้น
- องค์ประกอบ: การ์ดมุมโค้ง เงานุ่ม ไอคอนเส้น และมาสคอต 3D
- การจัดหน้า: ใช้คอมโพเนนต์ของ React Native เช่น `View`, `Text`, `Pressable` และ `ScrollView`

## หน้าจอหลัก

เข้าสู่ระบบ / สมัครสมาชิก, หน้าหลัก, ห้อง, ปรับแสงไฟ, อัตโนมัติ, ประวัติ, ตั้งค่า และผู้ช่วย

เมนู ปุ่ม คำแนะนำ สถานะ และข้อความสำหรับโปรแกรมอ่านหน้าจอใช้ภาษาไทย รวมถึงข้อความผิดพลาดทั่วไป ชื่อแบรนด์ ชื่ออุปกรณ์ที่ผู้ใช้ตั้ง และรายละเอียดทางเทคนิคสำหรับตรวจสอบปัญหายังคงค่าต้นฉบับ หน้า “ภาษา” ระบุภาษาไทยที่ใช้งานอยู่ ยังไม่มีตัวสลับภาษา

คีย์นำทางและค่าที่ส่ง API คงเดิม โดย `src/thai.ts` แยกชื่อเมนูที่แสดงออกจากคีย์ระบบ
